# Controle Oxigenio Aquario

## Descrição do Problema
Monitorar os níveis de oxigênio dissolvido em aquários de laboratório e identificar quais precisam de intervenção imediata.

## Requisitos
- Ler dados de oxigênio (mg/L) para vários aquários
- Alertar se o nível for menor que 4.5 mg/L
- Exibir o aquário com o menor nível de oxigênio

## Exemplo de Uso
Entrada: 5.2, 3.8, 6.1, 4.2

Saída:
AVISO: Aquario 2 (3.8 mg/L)
AVISO: Aquario 4 (4.2 mg/L)
Menor nivel: Aquario 2 com 3.8 mg/L
